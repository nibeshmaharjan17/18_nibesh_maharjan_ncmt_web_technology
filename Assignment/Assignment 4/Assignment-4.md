## Group A: Short Questions (2 Marks)

### 1. Differentiate between Legibility and Readability.

Answer: Legibility refers to the ease with which someone can tell individual letters or characters apart in a font. This depends on the design of the font itself. Readability refers to how easily someone can understand the text as a whole. Layout, spacing, and how complex the writing is affect readability.


### 2. What is the ”Rule of Thirds” in layout design?

Answer: The Rule of Thirds involves dividing a page or image into a 3 X 3 grid (two horizontal lines and two vertical lines). Placing the most important elements at the intersections of these lines or along them creates more balance, energy, and visual interest than simply centering the content.

### 3. Why should you limit the number of font families used on a website?

Answer: You should limit fonts (ideally to 2 or 3) because:

Performance: Loading multiple font files increases page load time.

Consistency: Too many fonts make a site look cluttered and unprofessional.

Clarity: Limiting fonts helps establish a clear visual hierarchy for the user.

### 4. Define ”Responsive Web Design.”

Answer: Responsive web design is a method of building sites so they offer a good viewing experience on many kinds of devices. This means easy reading and navigation with as little resizing, panning, and scrolling as possible, no matter if you're using a phone or a computer.

### 5. Explain the ”F-Pattern” of scanning and how it influences the placement of content on a
web page.

Answer: Eye-tracking studies have shown a pattern in how people typically look at websites with lots of text, such as blogs and news pages. This pattern is often called the F-Pattern.

When visiting such a site, people usually start by reading across the top part of the page in a horizontal direction. Then, they move down and read across again, though usually this second line is shorter than the first. After that, they tend to scan down the left side of the page in a vertical motion. This is where the F shape comes from.

This pattern has some implications for web design. The areas where people look the most are at the top and on the left side. For this reason, it's a good idea to put important things in these hot zones. This could include headings, calls to action, or logos. Content that isn't as important can be placed on the right side or further down the page, since people don't always look at those areas as much. Understanding the F-Pattern can guide decisions about where to put things on a webpage to grab visitor attention better. Using this knowledge, designers may improve the site's message and user .

### 7. Explain the ”60-30-10 Rule” regarding color balance on a website.

Answer: When designing a website, a handy guideline for color balance is something called the 60-30-10 Rule. It's a simple formula that can assist create a visually pleasing color scheme.

*   **60% (Main Color):** This usually involves a neutral color, like white, gray, or a muted tone. Think of it as the backdrop for your content. This color is generally used for the background and other large areas of the website. Because it serves as the primary canvas upon which all other elements are placed, it is vital that this color does not interfere with readability or distract users from the material.

*   **30% (Supporting Color):** This color gets used for things like headings, sidebars, or even smaller navigation menus. The goal is to make these elements stand out a bit from the background without being too distracting. A supporting color should provide enough contrast to separate parts for clarity and layout.

*   **10% (Color pop):** Save a brighter, more noticeable color for small details. This is great for things like call-to-action buttons, icons, or important links. The purpose of using an accent color sparingly in these areas is to immediately draw people's attention and guide them to take a desired action. Be careful not to overuse this color so it will keep its attention-grabbing power.

### 8. A website loads very slowly, causing users to abandon it. Upon inspection, you find the developer used high-resolution raw images directly from a camera. Explain the importance of Image Optimization and file formats (JPEG vs PNG) to solve this.

Answer: Image file size and formatting are very important for anyone publishing content online. Large image files impact website loading speed, which in turn affects the user experience and how search engines rank the site. Image optimization is about reducing the file size of an image without sacrificing too much visual quality.

For image optimization, large, high-resolution raw images, which can be 10MB or more, are not ideal for websites. The goal is to decrease the image file size to a manageable level. Doing this will reduce the Time to First Byte, which refers to how long it takes for the browser to get the first byte of data from the web server. Quicker loading times are critical for keeping visitors engaged and can also boost search engine ranking.

Choosing the proper file format for the image is also very important, and the two most common formats are JPEG and PNG.

JPEG is best suited for photographs and complex images with many colors and gradients. It uses a method called lossy compression. Lossy compression reduces file size by discarding some image data. For most photos, the level of data loss is not very noticeable to the eye, and the file size reduction can be very substantial.

PNG works best for graphics, logos, images with flat colors, or any image where transparency is needed. It uses lossless compression, which preserves all of the image data during compression. The images retain sharp edges and fine details. Because no data is lost, PNG files tend to be larger than JPEG files, especially for photographs.

### 10. A website looks great on a laptop but is unreadable on a mobile phone because the user hasto zoom in and scroll horizontally. Identify the design principle missing here and explain how Media Queries/Fluid Grids could fix it.

Answer: **Addressing the Absence of Responsiveness in Design: A Mobile-Centric Strategy**

A key design consideration that seems to be absent is responsiveness, particularly concerning a mobile-first design approach. In modern web creation, it is vital that digital content adapts seamlessly to different screen sizes and devices. It makes sure a consistent and user-friendly experience for everyone, no matter if they are on a desktop, tablet, or smartphone. When responsiveness is missing, users may face layout problems, small text, and navigation difficulties on smaller screens, which can hurt user satisfaction. To tackle this, here are some solutions to help implement responsiveness:

*   **Media Queries:** Media queries are a helpful tool in CSS that let designers apply specific styles based on the features of the user's device, most commonly screen width. For example, using `@media (max-width: 600px)`, you can set rules that rearrange page elements for screens smaller than 600 pixels. In this setting, a typical change is to have elements that are side by side on a desktop site stack vertically on mobile devices. A change makes content easier to view and interact with on smaller screens.
*   **Fluid Grids:** Traditional fixed-width layouts use pixels to define element sizes, which can cause display issues on different screen sizes. Instead, using fluid grids, which use relative units like percentages or viewport widths, can solve this. A setting lets elements scale smoothly, relative to the screen size. For instance, setting an element's width to `100%` makes it take up the entire width of its container, adapting to any screen size. The flexible approach makes sure your design looks good on a wide range of devices, offering a more consistent user experience.
